A FEW FIELD NOTES

Learn one correction at a time.

01 / CATCH

Start with the lean.

Choose “All push, no damping” to try P alone. Increase P and watch it catch, overshoot, and swing back. Too little force lets gravity win.

02 / SETTLE

Give it a brake.

Increase D to resist angular motion. Repeat the same push and compare the oscillations. A useful tune catches the stick and settles.

03 / EXPLORE

Make it work harder.

Add a steady tip force and explore a little I. Turn off “Return to center” to isolate angle control and see why an upright stick can still drift.

What is actually being simulated? +

A 0.3 kg uniform rigid rod, 1.4 m long, pivoted to a 1.0 kg translating base. The circle is a visual wheel; there is no rolling inertia, tire slip, or free contact between rod and ball. Gravity, base friction, rod inertia, and motor saturation are included.

The nonlinear equations run at 240 steps per simulated second with RK4 integration. Pushes apply an impulse at the rod tip. The track ends at ±3.2 m; a run ends at 70° of lean. Reset starts a new run with the same settings.

Angle is positive to the right. The inner controller uses e = angle − target in radians and force = Kp·e + Ki·∫e dt + Kd·angular velocity. Positive force moves the base right. Gain units are N/rad, N/(rad·s), and N·s/rad. Derivative uses measured velocity; integral has conditional anti-windup.

When enabled, a fixed, slower position loop requests up to 10° of lean to return the base to the origin. This is separate from the angle PID. The default uses PD with I = 0. Learn more from MIT’s cart-pole notes ↗.
